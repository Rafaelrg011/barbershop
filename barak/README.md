# BARAK · Demostración comercial

Sistema de demostración con logo oficial de Barak, 12 clientes ficticios, tres profesionales y cuatro servicios. Incluye agenda, fidelización, caja, propinas, salarios y reportes.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube los archivos extraídos a la raíz de tu repositorio: index.html debe quedar al mismo nivel que README.md y barak-logo.png. No subas solamente el ZIP.
3. En Settings → Pages selecciona Deploy from a branch, rama main y carpeta / (root), y guarda.
4. Abre el enlace de GitHub Pages cuando termine la publicación.

No necesita instalación, compilación, Firebase ni claves. Las rutas relativas permiten publicarlo dentro de un repositorio de GitHub Pages. También se puede desplegar como sitio estático en Netlify desde GitHub, usando la raíz como directorio de publicación y sin comando de compilación.

## Presentación al cliente

- Elige Propietario para ver todas las secciones, o cambia a Recepción y Barbero.
- Clientes: Carlos tiene nueve visitas, Andrés ocho y Gabriel cuatro.
- Agenda: cobra el saldo de Bs 35 de la cita de Andrés y márcala completada para mostrar la novena visita.
- Caja: muestra fondo inicial, cobros en efectivo y QR, propina y cierre.
- Salarios: muestra el salario de Marco y su descuento de ejemplo.
- Reiniciar demo restaura los ejemplos con fechas actuales y borra solamente los cambios de esta demostración.

Los nombres y operaciones son ficticios. Los teléfonos están vacíos. Los cambios se guardan en el navegador y no se sincronizan entre dispositivos. No utilizar esta demo como sistema de producción.
